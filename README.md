# HW rec downloads
Official customer Windows releases for HW rec. Download the executable from Releases.
Install v1.0.7 manually once to enable silent startup updates. Future newer stable releases are downloaded in the background, checked against GitHub SHA-256, and installed when the app is idle. Failed update checks leave the current app running.
This repository contains customer downloads only. Account-server source, administrator tools, keys, and customer data are not published here.
